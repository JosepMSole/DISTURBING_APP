INSTALACIÓN ANDROID

Si Chrome no ofrece instalar la PWA, puedes usar la APK Android firmada. La App seguirá cargando el contenido web actualizado.

1Descarga la APK.
2Abre el archivo descargado.
3Si Android lo solicita, autoriza temporalmente la instalación desde este navegador.
4Instala y abre Disturbing Stories App.
COMPROBANDO APK…SEGUIR USANDO DESDE EL NAVEGADOR

Android puede mostrar avisos de seguridad propios del sistema. No es posible eliminarlos desde la web. Si no quieres instalar, puedes seguir usando la App desde el navegador.
